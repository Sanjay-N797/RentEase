System Architecture & Key Features

Engineered for real-world rental operations with production-grade security standards.

🏎️ Multi-Category Fleet

Flexible booking rules tailored for two-wheelers (MCWG), compact hatchbacks, luxury sedans, and group vans (HMV) with branch allocation.

🔒 Transaction Safety

InnoDB row-level locking (SELECT ... FOR UPDATE) eliminates double-booking race conditions across simultaneous booking attempts.

⚡ Smart Waitlist Engine

When dates clash, users can opt into a FIFO queue. Cancellations automatically promote and notify next-in-line bookings.

🛡️ Security Hardened

CSRF tokens, parameterized PDO queries, role authorization middleware, brute-force lockout, and file upload MIME verification.

📊 Admin Analytics

Fleet utilization metrics, booking returns handling, revenue breakdown, and one-click CSV report exports.

💻 Local & Server Ready

Full PHP 8 PDO codebase ready for Apache/XAMPP or Docker, with automated database migration and seeding scripts.
